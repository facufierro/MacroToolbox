# MacroToolbox v6.3.1

## Changes

- Made opening a newer app build replace an older running instance before automatically upgrading saved settings, including when the older app was in the tray.
- Preserved a backup before every settings upgrade, including skipped versions, and kept the original settings intact if the backup could not be saved.
- Stopped startup after a settings load failure instead of applying default startup settings and removing the existing login registration.
