# MacroToolbox v6.3.0

## Changes

- Kept overlay order above borderless games independent of renderer polling, including after secondary-monitor focus changes, without taking keyboard focus.
- Fixed shortcuts shared by several profiles so they enabled and disabled the matching profiles together.
- Prevented behaviors from blocking a profile toggle assigned to the same shortcut.
- Added Number, Text, and Keys variables shared across profiles.
- Made variables selectable in behavior fields and added creating and saving a variable directly from a behavior.
- Replaced unsaved variable rows with explicit editing and Save and Cancel actions.
- Added drag-and-drop ordering for folders, profiles, hotkeys, events, overlays and their parts, scripts, states, variables, and behavior steps.
- Made overridden profile items follow their saved order while keeping inherited items in their source profile's order.
- Added On press and On release choices to Press and Mouse press behaviors.
- Kept behavior controls inline when space was available and widened the hotkey and event editors to reduce unnecessary wrapping.
- Added reusable Trigger list variables and a Matched trigger source for Press, so several shortcuts could share one behavior and replay the shortcut that activated it.
- Separated hotkey, state, and script titles from their type labels in the item lists.
- Added Secure send for hotkeys, with masked password editing, Windows Credential Manager storage, and password-free profiles, exports, backups, runtime files, and error messages.
- Prevented development builds from replacing the Windows login target with an executable that required the development server.
- Fixed Mouse press double clicks so games could observe each click before following text or password steps, while preserving window-based delivery.
- Made Ctrl/Shift mouse presses finish delivery before following text steps.
- Fixed Single click using the same press timing as Double click, so games could register one click without requiring a second.
- Fixed recording Copilot as a trigger so it captured Right Ctrl without the internal menu-mask key or a phantom Shift.
- Removed the extra unassigned key sent before Right Ctrl by the Copilot remap, so games no longer received that stray keypress.
- Respected Windows' native Copilot-to-Right-Ctrl setting instead of intercepting and simulating the key a second time.
- Preserved held shortcut modifiers during Type text and Secure send instead of releasing and pressing Ctrl again.
- Stopped input and released macro-owned keys and mouse locks after unexpected input errors, without leaving a blocking error dialog.
- Added reusable Behavior variables containing complete action sequences, with Save as variable, nested shared behaviors, and references from hotkeys and events.
- Restored text output from Alt shortcuts such as Alt+R without disturbing held Right Ctrl or reactivating Alt after it was released.
- Added Toggle keys to hold selected keys after one hotkey press and stop the behavior on the next press.
