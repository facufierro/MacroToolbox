# MacroToolbox v4.4.0

## Changes

- Added a fit behavior that expands a window to its monitor while keeping its original aspect ratio and filling unused space with black bars.
- Improved fit, stretch, and borderless compatibility with DPI scaling, window restoration, and switching between sizing modes.
- Removed the extra compatibility notice and fit description from the behavior editor.
- Fixed fit bars appearing gray with some Windows themes; they now use solid black.
