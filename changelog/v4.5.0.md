# MacroToolbox v4.5.0

## Changes

- Added a mousepress behavior using AutoHotkey's built-in ControlClick, with existing pressalt behaviors kept compatible.
- Fixed mousepress to create a fresh click while the mouse button is held, then preserve its current held state.
- Fixed borderless changing a game's client resolution when removing the window frame or returning from a sizing mode.
- Fixed fit to enlarge the displayed game image while preserving its render resolution and aspect ratio, with solid black bars in the unused monitor area.
- Fixed Windows-key shortcuts, including Win+R, while keeping the Copilot key's Right Ctrl remap.
- Fixed fit's black backdrop to cover the monitor's outer edges and corners without visible window borders.
- Added a resolution behavior that sets the target app's monitor to a configured width and height.
- Fixed key remaps to keep working with held modifiers, so Shift+X sends Shift+Y when X is mapped to Y.
