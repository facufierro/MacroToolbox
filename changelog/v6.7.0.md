# MacroToolbox v6.7.0

## Changes

- Added detailed, timestamped diagnostic logs with hotkey runs, action timings, focus and cancellation reasons, individual mouse-button transitions and cleanup, cursor locks, and requested versus actual cursor positions, with session files and a copyable console.
- Improved password-save and Secure send errors to identify the failing operation and Windows error code without logging passwords or typed text.
- Combined key and mouse presses into one Press action with single/double clicks and an optional Compatibility checkbox; existing saved actions automatically kept their original input method.
- Fixed delays following slower input actions so each sleep runs for its configured duration.
- Fixed copied behaviors sharing editable overlays with their originals; copies now keep independent overlays, parts, and timer links.
- Added overlay bars that automatically line up whole spell overlays horizontally or vertically, with adjustable pixel gaps, a shared position, and drag ordering.
