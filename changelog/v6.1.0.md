# MacroToolbox v6.1.0

## Changes

- Fixed modified hotkeys such as Alt+R leaking their plain key repeats or release when the modifier was released during the command.
- Kept overlays at their configured position after Alt+Tab by waiting for the current target's valid bounds and rejecting stale position updates.
- Fixed hotkeys that sent their own trigger, such as E, leaving that key held and blocking subsequent presses.
- Added a per-timer option to hide the text background.
- Added duplication of complete overlays with their parts and timer visibility links.
- Removed copy controls from individual overlay parts.
- Fixed confirmation dialogs for deleting overlays, profiles, and folders or stopping an app, including respecting Cancel before taking action.
- Fixed fast Copilot shortcuts reaching games before Right Ctrl was held by completing the modifier handoff before forwarding the next key.
- Fixed delayed Copilot recognition retaining the chord's Win/Shift modifiers while preserving independently held modifier keys.
- Replaced editable overlay part names with automatic labels using the overlay name, part type, and a number starting at zero for each type.
- Kept the first overlay part at its configured position when wider or taller parts were arranged alongside it, while preserving centered alignment.
