# MacroToolbox v6.5.0

## Changes

- Added a separate Cancel triggers list to hotkeys so any configured key or mouse button can stop their running behavior list and release held inputs. Existing saved cancel keys automatically become one-entry lists.
- Condensed cancel-key editing into a compact, visibly labeled Cancel on dropdown beside the hotkey trigger, with icon actions and tooltips.
- Added Another behavior starts under Cancel on to stop a running list when another behavior begins, including across profiles.
