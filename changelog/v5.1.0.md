# MacroToolbox v5.1.0

## Changes

- Fixed waitfor chains missing quick keyboard presses and mouse clicks while waiting for their next step.
- Added an Only while running timer visibility option, selected by default for new timers, so timers can appear when started and hide automatically when they expire without setting up states.
- Added a Restart choice to overlay actions so repeated casts can restart an active timer; existing Start actions keep their remaining countdown.
