# MacroToolbox v4.3.0

## Changes

- Added Google account sign-in and automatic Firebase backup and restoration of settings, folders, profiles, hotkeys, overlays, images, sidebar width, and linked script files.
- Included the MacroToolbox Firebase connection so users can sign in without importing project configuration.
- Added Firebase connection setup in Settings, offline saving, and a choice between local and cloud copies when setups differ, with a local recovery copy before restoring.
