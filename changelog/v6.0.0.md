# MacroToolbox v6.0.0

## Changes

- Unified hotkeys and app events around behaviors with nested sequences and simultaneous action groups.
- Added modifier combinations to mouse presses and made repeated presses work with multiple keys and inside sequences.
- Stopped running behaviors and released their owned inputs when their target lost focus or their profile was disabled.
- Updated profile bindings without restarting the shared keyboard hook or interrupting unrelated behaviors.
- Moved states into target folders so hotkeys, events, overlays, and scripts shared one definition and runtime value.
- Kept countdowns running across focus changes and made all enabled overlay profiles in a folder display together.
- Added explicit state entry and exit, overlay stopping, editable bar values, and script actions to behaviors.
- Added Python and AutoHotkey APIs for shared states, overlays, bars, and managed behaviors.
- Stopped managed scripts when their owner or calling profile was disabled, or their target lost focus.
- Preserved behavior text and nested references through editing, copying, and import/export, and reported unsupported actions instead of silently dropping them.
- Surfaced runtime activation failures.
- Made cursor actions use their own target window independently of the active overlay.
- Stopped existing managed script instances when their script definition or target changed.
- Kept mouse press modifiers held around click delivery and preserved them when another behavior shared the same modifier.
- Restored individual behavior buttons, with the original actions in their previous order and the new actions available in the same style.
- Combined hotkeys, app events, overlays, scripts, and state controls in one profile editor instead of separating them by profile type.
- Added overlay groups with shared placement, side-by-side or stacked layouts, part ordering, and a shortcut for adding a hotkey that starts the group.
- Let icons and other overlay parts follow a timer directly, and let an entire group appear only while its selected timer was running.
- Preserved group membership and timer relationships through copying and import/export, and removed stale links when parts were deleted.
- Made States and Scripts collapsible in the profile editor.
- Added independent enable switches to profile sections and overlay groups, stopping their owned work while keeping other sections running.
- Added a shared folder switch for States that cleared active states and their countdowns when disabled.
- Kept managed script actions tied to their calling section and defining script profile so disabling either stopped their work.
- Added a collapsible bottom console for app, overlay, cloud, and runtime errors, replacing error popups with timestamped messages, repeated-error counts, Copy, and Clear.
- Identified missing overlay references in behavior selectors and included the target and calling profile in runtime errors.
- Made overlay groups start with their parts and add controls, moved configuration into compact collapsible settings, and labeled arrangement, spacing, visibility, and position controls.
- Fixed hotkeys swallowing fresh key presses while an earlier activation waited for input or a delay; each fresh press now replaces the pending activation and sends its configured actions again.
- Fixed rapid key releases failing to rearm hotkeys whose actions had already finished.
- Replaced the separate group and standalone-part creation controls with one **+ Overlay** button; timers, icons, bars, and text were added inside each overlay.
- Wrapped existing standalone parts in overlay containers while preserving their IDs, positions, and hotkey references, and made confirmed overlay deletion remove its owned parts.
- Removed the preview from the overlay editor.
- Replaced delete-button crosses with Font Awesome trash-can icons.
- Converted action buttons to compact Font Awesome icons with accessible names and hover labels, including section add buttons, overlay parts, settings, and behavior actions.
- Used checkmarks for accepting edits and back arrows for cancel actions.
- Gave Cancel buttons a neutral fill and brighter arrow to balance their appearance with Accept buttons.
- Replaced overlay arrangement arrows with visible Horizontal, Vertical, and Individual positions buttons.
- Restored visible labels for position picking, key recording, file browsing, behavior choices, overlay parts, and cloud actions.
- Moved overlay settings above their parts into a compact grouped form, and labeled the size, color, duration, and visibility fields in part editors.
- Kept arrangement choices equal in size when highlighted and standardized icon-button dimensions across button styles.
- Removed the redundant settings shortcut and blank profile-list spacing inside empty folders.
- Made Hotkeys, Events, and Overlay collapsible alongside Scripts and States, independently of their enable switches.
- Renamed the profile's Overlay section to Overlays.
