# MacroToolbox v5.0.0

## Changes

- Fixed timer and other overlay items appearing away from their configured coordinates on scaled displays and desktops with monitors left of or above the primary screen.
- Set new profiles' default names to their corresponding types: Hotkeys, Events, Scripts, or Overlay.
- Replaced overlay dismissal groups with shared visibility states; right-clicking a state-linked item now deactivates its state, and triggering the state shows its items again.
- Added a States button to profiles and made states selectable by hotkeys, events, and overlay items in the same folder.
- Added a Start with overlay checkbox for timers, including immediate starts when enabled on an active overlay.
- Added a startoverlay behavior to start a selected overlay item without resetting an active countdown.
- Fixed fixed-duration timers remaining static and expired countdowns returning to their full duration.
- Added waitfor steps to pause a behavior chain until another key or mouse button is pressed, then continue its remaining actions.
- Fixed overlay timers resetting when switching windows; countdowns now continue while their overlays are hidden.
